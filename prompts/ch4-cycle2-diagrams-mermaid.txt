# Solution 1 — VERSION COMPACTE (recommandee pour le rapport)
#   Fichier : koda-cycle2-robot-flux1-vocal-compact.mmd

# Solution 2 — COUPER EN 2 PARTIES (detail complet)
#   Partie A : koda-cycle2-robot-flux1-vocal-partA.mmd (capture → STT)
#   Partie B : koda-cycle2-robot-flux1-vocal-partB.mmd (n8n → TTS → robot)

# Solution 3 — PlantUML avec box + newpage
#   koda-cycle2-robot-flux1-vocal-compact.puml  (box services cloud)
#   koda-cycle2-robot-flux1-vocal-split.puml    (2 pages PDF)
#
# Solution 4 — Mise en page draw.io (apres import)
#   - Reduire la police des lifelines (10–11 pt)
#   - Activer "Format → Page → Paysage" pour les sequences larges
#   - Exporter PNG en haute resolution puis \kodafigureL[1.0\textwidth]
#
# Solution 5 — LaTeX paysage (dernier recours)
#   \begin{landscape} ... \kodafigureL ... \end{landscape}
